# jdudgeon1993.github.io

Jordan Dudgeon's personal site, served free by GitHub Pages at https://jdudgeon1993.github.io

Plain HTML and CSS, no build step. Edit `index.html`, push to `main`, and it's live in about a minute.

- **Add a project:** copy one `<li><article class="card">…</article></li>` block in the Work section and change the words and link.
- **Update "Now":** edit the list in the Now section and the "Updated" month.
- **Email signature images:** `img/jd-badge.png` (with the duck) and `img/jd-monogram.png`. Signatures load these, so don't rename or delete them.
